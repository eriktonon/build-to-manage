          Canonical 11 IBM Build to Manage Practices — Repository Implementation Matrix

            #
            BTM Practice
            Standard Endpoint / Artifact
            Operational Shift-Left Capability
            Status
          

        
        
          

            01
            HealthCheck API (L1–L5)
            GET /health/{live,ready,deep}
            Separates process liveness from dependency readiness and executes L5 synthetic read-after-write probes (`HealthCheckAPIs/python/frameworks/redishealthcheck.py`).
            VERIFIED
          

          

            02
            Log Format & Catalog
            catalog/event-and-log-catalog.json
            Emits single-line structured JSON logs with mandatory `trace_id`, `span_id`, `transaction_id`, `event_code`, and `release` fields.
            VERIFIED
          

          

            03
            Monitoring & Golden Signals
            GET /metrics (OTel / Prom)
            Exposes latency histograms (P95/P99), error rate, saturation, and SLO error budget burn rate.
            VERIFIED
          

          

            04
            Deployment Correlation
            release.{version,commit_sha}
            Stamps every log, trace span, health response, and FFDC snapshot with exact Git SHA and build version to correlate regressions immediately.
            VERIFIED
          

          

            05
            Distributed Tracing
            W3C traceparent + X-Global-Tx-Id
            Propagates W3C TraceContext across `service1 → service2 → service3` (`DistributedTrace/python/`).
            VERIFIED
          

          

            06
            Topology Information
            GET /manage/topology
            Self-declares upstream callers and downstream dependencies so AIOps understands blast radius dynamically.
            VERIFIED
          

          

            07
            Event Format & Catalog
            CloudEvents v1.0 (BTM-*)
            Deterministic catalog of operational and business events with pre-assigned severity and SLO impact.
            VERIFIED
          

          

            08
            Test Cases & Synthetic Scripts
            tests/test_btm_contracts.py
            Automated pre/post-deploy contract and synthetic smoke test suite verifying all manageability endpoints.
            VERIFIED
          

          

            09
            Runbooks as Code
            GET /manage/runbooks
            Links every `event_code` (`BTM-HC-5001`, `BTM-TRC-5001`) to deterministic diagnosis, remediation, and `CAU Group` (`runbooks/RUNBOOK-CATALOG.md`).
            VERIFIED
          

          

            10
            First Failure Data Capture (FFDC)
            GET /manage/ffdc
            Automatically snapshots call context, headers, and stack trace on the very first anomaly—eliminating bug reproduction delays.
            VERIFIED
          

          

            11
            Living Documentation & Gate
            README.md & BTM.png
            Versioned architectural blueprint and operational readiness checklist kept in lockstep with code.
            VERIFIED
